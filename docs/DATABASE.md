# Database

No database is used or required. Supabase client code, SQL migrations, seed generation, member records, assignments, submissions, approvals and their database-specific tests have been removed together with the corresponding features.

All learning content is version-controlled public data in src/data.ts and src/initiatives.json. The website stores no member information or shared progress. There is no need to connect Supabase or MongoDB for the current scope.

No hosted database was provisioned by this work. If a database was configured independently, this code change does not delete that external database or alter its settings.
