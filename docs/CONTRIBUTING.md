# Contributing

Use npm ci and npm run dev. Make focused changes on a feature branch, run the documented checks and open a pull request. Never push directly to production to skip review.

Update content through source files as described in CONTENT_GUIDE.md. Keep every track and exercise openly accessible. Preserve original initiative/milestone IDs and avoid presenting proposed projects as released.

Run lint, strict typechecking, unit tests, desktop/mobile browser tests and production build. Include relevant screenshots and actual verification results. Never commit credentials or private member data.
